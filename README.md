## Introduction

本项目为岭南师范学院“爱心驿站”提供业务系统支持。

> "爱心驿站"创立于 2013 年 6 月，是岭南师范学院为家庭经济困难学生提供完善、到位的资助与帮扶而设立的非营利性质的家庭经济困难学生资助平台。经学校认证的家庭经济困难学子，在驿站购买生活用品和学习用品时，可享受相应折扣。
