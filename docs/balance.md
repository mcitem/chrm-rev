## 余额

驿站对学生每年能够购买的商品总价值有限制，这个限制称为"余额"，即"剩余额度"。

默认配置下，余额按商品原价扣除

[更改配置](./configloader.md)

### 默认配置下的初始额度

| 认定级别 | 每学年余额 | 购买价格 |
| -------- | ---------- | -------- |
| 一般困难 | 70.00      | 7折价    |
| 困难     | 100.00     | 5折价    |
| 特别困难 | 150.00     | 3折价    |

::: info
每**学年**拿到新的贫困认定数据并重新导入后余额才会重置
:::

## 余额不足

如果剩余额度不足(-5.00)元时，才会提示余额不足，若小额超出（例如-0.1等）情况可酌情允许购买。

如果提示余额不足，请酌情删减购买的商品
