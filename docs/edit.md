# 编辑数据

**如果需要编辑，你应该在首页无记录时进行**

## 如何修改部分商品信息？如商品价格更新了，但是学生数据不变，如何编辑？

### 方法一：通过数据导出再重新导入

使用`菜单-管理-数据导出`工具，将数据库导出到execl文件中。

在execl中编辑完成后

::: warning
修改时注意：商品id、学生id、学生学号这三列都不能重复！！！
:::
使用`菜单-管理-数据导入工具`，备份并清除原有数据库，然后跟随引导导入你修改后的execl文件。
::: warning
修改后在导入时，学生的余额列必须要指定，才不会丢失已有的学生剩余额度数据（否则又会被重新初始化成满额度。
:::

### 方法二：使用datagrip直接对数据进行编辑

[datagrip](./datagrip.md)

## 新的学年开始了，如何导入新的学生数据？

新学年开始时，使用`菜单-管理-数据导入工具`，跟随引导进行备份并删除旧的数据库，然后导入新的学生、商品数据。
