# 编辑数据

## 在页面中直接编辑（推荐）

从首页左上角菜单进入 **管理 → 学生与商品管理**，切换“学生资料”或“商品资料”。

- 点击单元格直接输入，困难级别使用下拉选择；学生编号和商品编号不可修改。
- 使用 Tab 切换单元格，Enter / Shift+Enter 上下移动，Esc 撤销当前格，也可以撤销整行。
- 从 Excel 复制连续多行、多列，从目标单元格粘贴；范围应在当前页内，学号前导零会保留。
- 修改的单元格会高亮。搜索、翻页、切换资料时保留修改，点击“保存全部修改”或按 Ctrl+S 统一保存。
- 点击“新增学生”或“新增商品”添加空白行，填完后统一保存。编号显示“待分配”，保存时由系统按当前最大编号加一分配，不能手工修改。
- 点击行末“删除行”标记删除，保存前可以“撤销此行”；新增草稿行删除后直接移除。删除不会重新排列其他编号，有购买记录关联的学生或商品不能直接删除。
- 姓名、商品名称和学号不能为空，学号不能与其他学生重复；金额最多两位小数，商品价格不能为负数。

保存时整批提交，任一行失败都不会部分保存，页面会保留草稿。若提示数据已变化，请先记下需要的修改，再放弃修改并刷新后重试。

学生余额可直接调整；修改困难级别不会重新初始化余额。已有购买记录保留原学号、困难级别、商品名称、规格及价格快照，新的资料和价格用于后续新增购买记录。

新增学生的初始困难级别为“不困难”、余额为 0，请按实际情况填写；选择困难级别不会自动改变余额。批量导入整份学生或商品名单仍可使用数据导入工具。

## 如何修改部分商品信息？如商品价格更新了，但是学生数据不变，如何编辑？

### 方法一：通过数据导出再重新导入

**使用重新导入或外部数据库工具前，应在首页无购买记录时进行。日常修改建议使用上方的管理页面。**

使用`菜单-管理-数据导出`工具，将数据库导出到execl文件中。

在execl中编辑完成后

::: warning
修改时注意：商品id、学生id、学生学号这三列都不能重复！！！
:::
使用`菜单-管理-数据导入工具`，备份并清除原有业务数据（保留系统配置），然后跟随引导导入你修改后的execl文件。
::: warning
修改后在导入时，学生的余额列必须要指定，才不会丢失已有的学生剩余额度数据（否则又会被重新初始化成满额度。
:::

## 新的学年开始了，如何导入新的学生数据？

新学年开始时，使用`菜单-管理-数据导入工具`，跟随引导进行备份并清空旧的业务数据（保留系统配置），然后导入新的学生、商品数据。
